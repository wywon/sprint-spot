# 실행 방법

모든 명령은 **`Node_Server` 폴더 안에서** 실행합니다.
VS Code 터미널은 저장소 최상위에서 시작하므로 먼저 이동해야 합니다.

```
cd Node_Server
```

---

## 매번 쓰는 것

### 서버 켜기

```
npm start          아두이노 연결했을 때
npm run mock       아두이노 없을 때 (가짜 데이터)
```

끄기: **Ctrl + C**

### 외부 접속 (터널)

새 터미널을 하나 더 열고:

```
cd Node_Server
npm run tunnel
```

서버와 터널 **둘 다 켜져 있어야** 외부에서 접속됩니다.

### 확인

```
로컬  : http://localhost:3000/api/parking
외부  : https://lens-salvage-unmixable.ngrok-free.dev/api/parking
상태  : http://localhost:3000/api/health
```

---

## 가끔 쓰는 것

| 명령 | 하는 일 |
|---|---|
| `npm run ports` | COM 포트 번호 찾기 (USB 꽂은 후) |
| `npm run db:check` | DB에 뭐가 들어있는지 보기 |
| `npm run db:test` | Oracle 접속 확인 |
| `npm run db:init` | 테이블 준비 (있으면 그대로 둠) |
| `npm test` | 파서 테스트 (아두이노·DB 불필요) |
| `npm run db:reset` | ⚠ 테이블 삭제 후 재생성. **데이터 사라짐** |
| `npm run api` | 수집기 없이 API만 |

`npm run` 만 치면 전체 목록이 나옵니다.

## 처음 받은 사람

```
cd Node_Server
copy .env.example .env
npm install
```

그다음 `.env`를 열어 본인 값으로 수정:

```
SERIAL_PORT=COM10          ← npm run ports 로 확인한 번호
DB_USER=parking
DB_PASSWORD=(팀에서 공유한 비밀번호)
DB_CONNECT_STRING=localhost:1521/XEPDB1
```

확인:

```
npm run db:test     → ✅ 접속 성공 / 접속된 계정 : PARKING
npm run db:init     → 10행 표
npm run mock        → 입출차 로그가 흐름
```

---

## 발표 당일 순서

1. Oracle이 켜져 있는지 — `npm run db:test`
2. 아두이노 USB 연결 → `npm run ports` 로 COM 번호 확인, 다르면 `.env` 수정
3. **아두이노 IDE 시리얼 모니터를 닫는다** (안 닫으면 서버가 포트를 못 엶)
4. `npm start`
5. 외부 접속 필요하면 새 터미널에 `npm run tunnel`
6. 브라우저로 `http://localhost:3000/api/health` 열어 전체 점검

노트북 절전을 꺼두세요. 화면이 꺼지면 USB 연결도 끊깁니다.

## 문제가 생기면

| 증상 | 원인 | 해결 |
|---|---|---|
| `Access denied` | 아두이노 IDE 시리얼 모니터가 열려 있음 | 모니터 닫기 |
| `File not found: COM10` | COM 번호가 다름 | `npm run ports` 로 확인 후 `.env` 수정 |
| `npm error ENOENT ... package.json` | 폴더가 틀림 | `cd Node_Server` |
| `ERR_NGROK_3200 offline` | 서버나 터널이 꺼짐 | 둘 다 켜기 |
| API에 HTML이 옴 | ngrok 경고 페이지 | 요청에 `ngrok-skip-browser-warning` 헤더 추가 |
| `ORA-01017` | DB 비밀번호 틀림 | `.env` 확인 |
| `ORA-12541` | Oracle이 꺼짐 | `services.msc` → OracleServiceXE 시작 |

값이 안 변할 때는 `/api/health` 의 `collector.lastLineAt` 을 보세요.
몇 분 전이면 아두이노가 멈춘 것이고, `database`가 `unavailable`이면 Oracle이 죽은 것입니다.
